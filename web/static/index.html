Settings for selected mode

Input Slots (Auto mode)

An input slot is one physical wire the simulator can read live NMEA from. Each slot has two settings:
• Function — what kind of data you say is on that wire (GPS position/time, SAT satellite compass, AIS traffic). This tells the router what to expect; it does not pick a port. One satellite compass legitimately feeds both the heading and GPS outputs, which is why function and port are separate.
• Adapter — which physical USB device the slot reads. Adapters are listed by their port and by what they are currently receiving, which is how you tell them apart. Leave it on “leave unchanged” to keep the current binding.
Changing the adapter takes effect on the next Stop → Start — it does not re-bind a running engine.

Switch to Auto mode to assign provisioned input slots.

Own-ship AIS identity (what this rig transmits as · persisted) MID —

This is the identity the AIS channel transmits as — own-ship goes out as !AIVDO, and Class A adds a Type 5 static report. Set it deliberately: the shipped default (MMSI 366000001) sits in an allocated MID, so it is plausibly a real vessel's. Name and call sign are restricted to the AIS 6-bit character set (upper case, digits and a few punctuation marks) — anything else is rejected on save rather than silently mangled on the wire. Class selects the message type: A emits Type 1 + Type 5, B emits Type 18 + Type 24. Persists via Save as defaults (applies on next Start).

Port Diagnostics (polled)

What this is: a read-only health readout for each live input port — byte counts, framing and checksum errors, and the last sentence seen. It never sends anything.
When to use it: a physical feed looks dead or garbled and you want to see whether bytes are arriving and parsing cleanly. Only populated in Auto mode with the engine running.
How to use it: nothing to click — the tiles below refresh on their own. Empty tiles here are normal in Simulate mode or with the engine stopped.

No per-port diagnostics — ports report only in Auto mode with a running engine.

Click-to-decode

What this is: an offline, field-by-field breakdown of any single NMEA 0183 or AIS sentence — each field named and its value explained, checksum verified.
When to use it: you have a line (from a log, a tap, or Port Diagnostics) and want to know what it actually says. Safe at any time — it touches no hardware and changes nothing.
How to use it: paste the line below and press Decode.

Active TX Controls (opt-in · bench ports only)

What this is: bench tools that write to a serial slot — auto-baud sweep, send a test sentence, loopback check, and raw capture. This is the only section on this tab that transmits.
When to use it: only against a port flagged as a bench port, when checking wiring, baud rate, or a device on the bench. Never against a port feeding real instruments.
How to use it: enter the slot id, then type the same slot id again in the confirm box to arm — a request with a missing or mismatched confirm is refused. If a request is refused: 409 means the slot is an operational (non-bench) port and will never be driven from here; 429 means the slot is in cooldown or already busy — wait a moment and retry.

Reference — baud / sentence / wiring / talker cheat-sheet

Baud rates

4800Standard NMEA 0183 talker rate (GNSS, heading, depth, wind)
38400High-speed NMEA 0183-HS (AIS receivers / transponders)
9600Common for some GNSS and instrument bridges

Common sentence formatters

RMCRecommended minimum: position, SOG, COG, date, time
GGAFix data: position, fix quality, satellites, HDOP, altitude
GLL / VTGGeographic position / course + speed over ground
HDT / HDGTrue heading / magnetic heading + deviation + variation
ROTRate of turn (degrees per minute, +stbd / -port)
DBT / DPTDepth below transducer / depth of water
MWV / VHWWind speed + angle / water speed + heading
VDM / VDOAIS received report / own-vessel report
ZDAUTC date & time + local zone offset
MWDWind direction (true & magnetic) + wind speed
XDRTransducer measurements (temperature, pressure, attitude, generic)
RSARudder sensor angle (port / starboard, degrees)
VDRSet & drift — water current direction + speed
PASHRAttitude: heading, roll, pitch, heave (proprietary)
THSTrue heading + mode / status indicator
HDMMagnetic heading (degrees)

Wiring / pinout notes

Differential pairNMEA 0183 uses a balanced A (+) / B (−) signal pair; keep it twisted
Reversed A/BBytes arrive but nothing is printable/framed — swap the A and B leads
Silent portNo bytes at all — TX/RX swapped, open line, or a dead talker
Multi-talkerMore than one talker on one listener collides — use a multiplexer
